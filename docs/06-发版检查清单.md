## 0. 前置：确定版本号

| 改了什么 | 版本位 | 例子 |
| --- | --- | --- |

| 纯修复、文案、显示细节 | 第三位 | 1.3.0 → 1.3.1 |

- [ ] **AE 界面**：右键供应仓（样板页）、右键接口仓三档位（配置槽、保持量、升级卡）

## 4. 提交与打 tag

```bash
git add -A
git -c i18n.commitEncoding=utf-8 commit -m "release: <ver> —— <一句话>"
git tag -a v<ver> -m "<ver>：<一句话>"
git push origin main && git push origin v<ver>
```

- [ ] 推送前确认代理在监听 `127.0.0.1:7890`（直连必失败，见 WORKSPACE_MEMORY §4）
- [ ] `git status -sb` 显示与 `origin/main` 同步
