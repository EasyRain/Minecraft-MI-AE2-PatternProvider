# 疑难排查

| 症状 | 最可能的原因 | 怎么办 |
| --- | --- | --- |
| 控制器显示**结构无效** | 同一阵列里放了两个供应仓 | 移除一个 —— 见[样板与自动合成](patterns.md) |
| 终端里合成一直显示**等待** | 供应仓没空间放产物，于是拒收材料 | 让网络把产物抽走，或给它腾地方；见下 |
| 完全没动静 | 没电 / 阵列里没插机器 / 用的是**工作台样板** | 见下 |
| 量子模块插不进去 | 它只认处理阵列控制器 | 普通机器上是预期行为 —— 请用高级模块 |
| 超大合成读档后从头开始 | 上游 `recipeEnergy` 的 `long`/`int` 截断 | 那条配方不要用量子模块 |
| 一次出多种流体时有一种凭空消失 | 上游多流体可行性检查的缺陷 | 把配方拆成几次合成 |
| Jade / TOP 显示**设备离线** | 没接线缆 / 没频道 / 网络没电 | 检查线缆，并给供应仓一个频道 |

## 终端里的「等待」

「等待」不是失败 —— AE2 每 tick 都会重试。在这里通常意味着：

* **输出槽满了。** 供应仓会**整体拒收**材料，而不是收下却做不出产物（那样产物会被销毁）。让网络把供应仓的输出抽走，
  或者给网络的存储腾空间，下一 tick 合成就会继续。
* **批量被拆开了。** 大合成会被拆成多次小批量，以免丢东西。合成会正常完成，只是步数更多。
* **批量大到离谱。** 单次推进每种材料的上限是 `输入槽数 × Integer.MAX_VALUE`。超过这个量的样板会被整体拒收并
  无限重试 —— 把样板拆成两条更小的即可。

## 合成根本不启动

按这个顺序检查：

1. **阵列成型了吗、有电吗？** 控制器应当是亮的，能源输入仓要接上 MI 线缆。记住阵列耗电是
   `配方 EU/t × 批数` —— 256 并行需要很大的供电。
2. **阵列里插机器了吗？** 打开控制器，把你想让它跑的电动物品机器插进去。没有机器 = 阵列无事可做。
3. **样板是处理样板吗？** 工作台样板（3×3）机器跑不了，请在样板编码终端里用处理样板模式重新编码。
4. **样板的输出与插入机器的实际产出对得上吗？** AE2 只认样板声明的输出，阵列产出的是机器真正产出的东西。
   两者不一致，合成就会一直等一个永远不会出现的产物。
5. **供应仓在线吗？** 用 Jade/TOP 悬停：显示**设备在线**才说明网络认得它。

## 量子模块没有带来并行

* 确认它插在**处理阵列控制器**里 —— 只有那里并行才生效。别的机器上量子与高级模块效果完全相同。
* 检查倍率：`config/mi_ae2_pattern_provider-common.toml` 的 `[quantum_overclock] parallel_multiplier`
  （2~16，默认 4），或者装了 Cloth Config 时在游戏内配置界面里改。启动日志里有该文件的绝对路径。
* 记住倍率是**天花板**：如果输入料量或输出空间只够 3 批，那配置写得再高也只有 3 批。

## 会被高倍率放大的上游问题

这些来自上游阵列代码，不是本 mod 引入的，但值得避开：

* **封装机的量子升级与聚变堆**：它们总 EU 太高，`总EU × 倍率` 可能超过 `2^31`，读档后合成进度会损坏
  （上游写档用 `long`、读档用 `int`）。装了量子模块时，这些机器请换回普通的高级模块。
* **一次出多种流体的配方**：可行性检查不扣减前一个流体产物的占用，某一份可能被截断而丢失。把这类配方拆开。
* **带概率产物的配方**：这类产物根本不参与可行性检查，掷中后装不下就丢了。这个问题在**原版** 64 并行时就已经存在。

## JEI 里找不到模块或这本手册

它们都在 **MI 自己的创造栏**里，紧跟 MI 原版超频模块之后。JEI 的物品列表就是各创造栏的内容，
不在任何栏里的物品在 JEI 里也搜不到 —— 找不到就去 MI 的通用栏里找。
